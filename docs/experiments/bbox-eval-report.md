## 1. 主张与结果（TL;DR）

- **H1 效率（墙钟双口径）**：
  - 平均单图墙钟：B **22.9s** vs C **34.1s**（C 含 AI 等待）；
  - 人工时段/图：B **22.9s** vs C **24.1s**（C 扣除并发 AI 批次 100.7s）→ **人工基本相当**；
  - C 的 AI 批次墙钟 100.7s，并发因子 **5.2×**（单图 AI 耗时之和 518.8s → 实际 100.7s）。
- **H2 质量**：C 的 AI 阶段 P@0.5 0.729 / R@0.5 0.714 / F1 0.722、标签正确率 0.828、采纳率 **0.896**；
  人工修正后 C 达 mAP 0.544 / AP50 0.770 / F1 0.742 / **标签正确率 1.000**。
- **H3 Agent 增益（B vs C）**：最终 mAP 0.541 vs 0.544（持平）；**标签正确率 0.973 vs 1.000**
  （LLM 语义映射消除错标）；代价：C 多约 100s AI 等待与 90,161 token / 10 图。

### 3.5 失败与边界案例

- `ai_generate` 10 张中 8 张成功；2 张失败原因均为「无有效 label_id 映射」，
  需人工兜底——这是采纳率之外的隐性成本，也是 map 阶段最值得优化的点。
- C 的 AI 阶段产生 2 个新增框（漏检补充），删除 0、移动 0：几何较稳，人工成本主要在改标签。

## 4. 统计分析

- 主口径为每条件 1 个墙钟观测（会话/人工时段），不做显著性检验；
- 辅助口径的单图耗时（同图配对，n=10）：Wilcoxon W+=42，双侧 p≈0.16，不显著（仅供参考）；
- 质量指标为点估计；n=10，未做 bootstrap 95% CI。

## 5. 局限性

1. 单一标注者（作者本人）；
2. 10 张小样本，且 **A 条件数据无效**，缺少手工基线；
3. 顺序/记忆效应未控制（同批图按 A→B→C 各标一遍；A 已排除）；
4. C 的 final 残留 2 个未标标签框；
5. 计时依赖埋点近似：审阅停留口径在「重复打开图片」时噪声较大；
6. YOLO/LLM 单版本，未做跨模型泛化。

## 6. 结论与改进

1. **人工成本**：C 的人工时段/图（24.1s）与 B（22.9s）基本相当，C 多出的成本是
   AI 等待（100.7s/批次，已并发 5.2×）与 token；
2. **质量**：C 的 LLM 语义映射把最终标签正确率提升到 1.000（B 0.973），
   修正后 mAP 与 B 持平（0.544 vs 0.541）；AI 阶段采纳率 0.896，几何基本可用；
3. **成本**：Qwen3.8-Max 下 AI ¥0.212/图 ≈ 人工修正时间成本 ¥0.200/图，C 总成本 2.16× B；
   换 Plus 级模型 AI 成本降至 ¥0.025/图，C 总成本 1.18× B——**成本可接近人工，
   但胜负取决于模型档位与 token 优化**（输出占 4,312/图）；
4. **待补**：重做 A（干净的手工基线）后可计算完整省时结论；补标 C 的 2 个遗漏框；
5. **下一步优先级**：map 阶段失败模式（2/10 张无有效映射）与 48.5s/图的映射耗时优化、
   减少每图 LLM 调用次数以压低 token 成本。
